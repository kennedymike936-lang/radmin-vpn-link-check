# Radmin VPN (蓝盾) 链路体检工具

一个用于检测 **蓝盾（Radmin VPN）** 联机链路的轻量 PowerShell 脚本。
当你和朋友联机时信号只有一格 / 延迟爆炸时，双击即可生成一份体检报告，判断问题出在哪。

> 蓝盾 = Radmin VPN：Radmin 的图标是蓝色盾牌，中文社区习惯叫它"蓝盾"，常用于 Minecraft 等游戏的虚拟局域网联机。

## 为什么会有"一格信号"？

Radmin VPN 是 P2P 虚拟局域网：理想情况下双方**直连**（国内跨省通常 30~150ms）；
但如果 NAT 打洞失败（手机热点/USB 共享双重 NAT、运营商大内网、防火墙拦入站等），
Radmin 会自动把流量**甩到官方中继服务器**兜底——而中继节点常在**境外（如欧洲 OVH）**，
于是延迟飙到 500ms~2000ms+，游戏/软件里就显示"一格信号"。

本脚本通过 **ping 延迟 + 中继服务器定位 + 上网链路/防火墙检查**，帮你判断当前是直连还是走了中继。

## 报告内容（6 段）

1. **蓝盾本体状态**：服务、界面进程、虚拟网卡、虚拟 IP
2. **寻找局域网同伴**：自动从 ARP 表发现同伴（也可手动指定 IP）
3. **到同伴的延迟测试**：平均/最小/最大延迟 + 丢包，自动判定直连/中继
4. **你的上网链路**：识别手机 USB 共享 / Wi-Fi / 有线，公网出口归属
5. **防火墙放行检查**：Radmin 入站规则是否就位、网卡网络类型
6. **蓝盾当前连接的服务器**：定位控制/中继节点归属地

## 使用方法

### 普通体检（无需管理员）

```powershell
# 双击 RadminCheck.bat 即可
# 或手动执行:
pwsh -NoProfile -ExecutionPolicy Bypass -File RadminCheck.ps1
```

### 一键修复（需要管理员）

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File RadminCheck.ps1 -Fix
```

会自动：把 Radmin 虚拟网卡/上网网卡设为"专用(Private)" + 补建 Radmin 防火墙入站放行规则。
**修复后建议双方都重启一次蓝盾**，让 Radmin 重新握手尝试直连。

### 可选参数

| 参数 | 说明 |
|---|---|
| `-PeerIP '26.x.x.x'` | 手动指定朋友 IP（自动发现不到时用） |
| `-PingCount 10` | 每次 ping 次数（默认 8） |
| `-SkipGeo` | 跳过服务器归属地查询（更快） |

## 判定标准

| 平均延迟 | 判定 |
|---|---|
| < 150ms | 直连良好 ✅ |
| 150 ~ 300ms | 一般，可玩但可能略卡 |
| > 300ms | 疑似境外中继 ⚠️ |

## 常见问题处理

- 延迟 >300ms：① 双方都重启一次蓝盾 ② 别用手机流量 / USB 共享（双重 NAT）③ 双方都执行防火墙放行
- 反复不行：Radmin 免费版中继节点在境外是硬伤，可换 **ZeroTier / Tailscale / 蒲公英**（对 IPv6 直连更友好）

## 兼容性

- Windows 10/11，PowerShell 5.1 或 7+
- 脚本为只读体检（无需管理员）；`-Fix` 模式需要管理员
